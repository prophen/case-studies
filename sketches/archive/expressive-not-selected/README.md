# Expressive Field Notes

## Design stance
A personal editorial portfolio, retaining the blue technical identity without documentation-style framing.

## Key choices
- Oversized sans/italic-serif typography and an original typographic illustration.
- Asymmetric homepage feature, cobalt project stage, and horizontal desktop chapter navigation.
- Quieter reading sections below a bold case-study hero.
- Linked homepage/detail page, native expandable decision, and preview-only proof dialogs.

## Trade-offs
More personality and visual contrast; less persistent chapter navigation than the original.

## Best for
Product-minded web and DevRel positioning.

## Boundaries
Disposable HTML, no production implementation or deployment. Product screens are illustrative; architecture and narrative require verification.
